## Active Source And Resources

- Active build and metadata live at `gradle.properties`, `settings.gradle`, `forge/build.gradle`, `forge/src/main/gradle.properties`, and `forge/src/main/resources/META-INF/mods.toml`.
- Active Java source lives under `forge/src/main/java/`.
- Active resources live under `forge/src/main/resources/`, especially `assets/tiered/`, `data/tiered/`, `data/forge/loot_modifiers/`, `echelon-defaults/`, and `tiered.forge.mixins.json`.
- Active project docs live under `docs/`.
- Root `resources/` contains repository-level image assets, not loader resources.

## Reference, Debug, And Ignored Local Folders

- `reference/`, including `reference/fabric_snapshot/` and `reference/context files/`, is ignored local reference material and not active source.
- `debugging_info/`, `.tmp_sources/`, and root `net/` are ignored local debug/reference folders and not active source.
- `forge/run/`, `forge/run-server/`, `forge/logs/`, `.gradle/`, build directories, cache directories, crash reports, and generated runtime files are omitted from this tree.
- Do not treat omitted reference/debug/runtime folders as active source unless a future task explicitly asks for historical comparison or local cleanup.
